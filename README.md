# Retail Sales Analytics Project

## Overview
This project analyzes 100,000 retail sales records using SQLite, SQL, pandas, NumPy, and Matplotlib.

## Files
- `retail_sales.db` - SQLite database with the `sales` table.
- `retail_sales_clean.csv` - cleaned dataset.
- `retail_sales_raw.csv` - raw dataset.
- `sql_workbook.sql` - 15+ business SQL queries.
- `analysis_notebook.py` - Python analysis script.
- `top_insights.csv` - top 5 business insights.

## How to Run
1. Open `retail_sales.db` with DB Browser for SQLite or SQLiteStudio.
2. Run `sql_workbook.sql` in the database.
3. Run `analysis_notebook.py` in Python.
4. Check the `output/` folder for charts and KPI summary.

## Key Insights
1. Identify top categories by sales and profit.
2. Compare regional performance.
3. Measure channel contribution.
4. Review monthly sales trend.
5. Check return rate and delivery days.
